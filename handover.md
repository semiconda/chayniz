## The vision (in my own words, across our conversation)

I'm learning Taiwanese Mandarin from zero. I need an app for:
- characters (recognition and recall),
- translation both directions (character/word → meaning, and meaning → character/word),
- mastering pinyin, including the parts that trip up a non-native speaker — sounds that don't map to English/French
  spelling the way they look (e.g. pinyin "yu" is always the ü sound, never "you"; "iu" is a contraction of "iou";
  "ui" is a contraction of "uei"),
- hearing a sound and recognizing which pinyin/character it is, and the reverse,
- short sessions — "quizzes" or small games I can do in spare 5-minute gaps, not long study blocks.

**Content pipeline.** Rather than building OCR/parsing into the app itself, the content (from the teacher's slides or
the reference book) is prepared *outside* the app: paste the material into any LLM session with a prompt that
defines a CSV format, get a CSV back, and drop that file into the app. The CSV should hold only the raw facts per
item (e.g. hanzi, pinyin, meaning, tags) — **not** question type or multiple-choice options. Those are generated by
the app at render time, so the same item can be asked different ways and multiple-choice distractors can be drawn
fresh each time from the rest of the dataset (this is where the "entropy" — not the same choices every time — comes
from: it's a property of the question generator, not of the stored data).

**Progression: the Leitner system.** Each item lives in a box/level. Right answer → promote to a less-frequent box
(daily → weekly → monthly → …, thresholds TBD in the spec); wrong answer → demote back toward the previous box.
Early boxes ask multiple choice; later boxes ask for typed recall (no choices shown). This needs persisted state
(scores, box assignment per item, last-seen date) — start with `localStorage` for v1; a real backend is a later
extension, not a v1 requirement.

**Scope for v1 vs. later:** v1 is a static page (GitHub Pages only, no backend) that loads a CSV, drills the
Leitner-scheduled items, and tracks progress in the browser. In-app upload-and-auto-generate from slides/PDFs
(parsing + an LLM call), a real backend/database for scores, and multi-language/global use beyond Taiwanese Mandarin
are explicitly beyond v1 — ask about them, but don't let them block the first plan.
